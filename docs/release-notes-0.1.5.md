# Auto Clicker 0.1.5

## English

- Adds **Ctrl+Shift+Escape** as an additional macOS emergency stop, while keeping Ctrl+Shift+F8.
- Shows only shortcuts successfully registered with the operating system and warns about registration conflicts. Clicking cannot start if no emergency shortcut is registered.
- On Mac keyboards configured for media keys, Fn or Globe may be needed with F8. Test the stop controls before unattended use.

Linux click automation requires X11. Windows installers are unsigned and may display SmartScreen warnings.

## 한국어

- macOS에서 기존 Ctrl+Shift+F8과 함께 **Ctrl+Shift+Escape** 긴급 중지 단축키를 추가했습니다.
- 운영체제에 등록된 단축키만 표시하고 등록 충돌을 안내합니다. 긴급 단축키가 하나도 등록되지 않으면 클릭 실행이 차단됩니다.
- Mac의 F8이 미디어 키로 설정된 경우 Fn 또는 지구본 키가 필요할 수 있습니다. 자리를 비우기 전에 중지 기능을 확인해 주세요.

Linux 클릭 기능은 X11이 필요합니다. Windows 설치 파일은 미서명 상태로 SmartScreen 경고가 나타날 수 있습니다.

## 日本語

- macOS に従来の Ctrl+Shift+F8 に加え、**Ctrl+Shift+Escape** の緊急停止を追加しました。
- OS に登録できたショートカットのみを表示し、登録の競合を通知します。緊急停止を登録できない場合はクリックを開始できません。
- Mac の F8 がメディアキーに設定されている場合は Fn または地球儀キーが必要になることがあります。無人で使う前に停止操作を確認してください。

Linux でのクリックには X11 が必要です。Windows インストーラーは未署名のため SmartScreen の警告が出ることがあります。
