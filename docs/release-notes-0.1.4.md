# Auto Clicker 0.1.4

## English

- Export settings to a JSON backup and import them on another installation. Invalid or cancelled imports keep the existing settings.
- Set a start delay of up to 60 seconds, and stop the run during that delay.
- Duplicate sequence steps, including their positions, to build a routine more quickly.
- Existing settings are retained when upgrading.

macOS requires Accessibility permission. Linux click automation requires an X11 session; Wayland is blocked because the emergency shortcut cannot be guaranteed. Windows installers are unsigned and may show SmartScreen warnings.

## 한국어

- 설정을 JSON 파일로 백업하고 다른 설치에서 불러올 수 있습니다. 잘못된 파일이나 취소는 현재 설정을 유지합니다.
- 시작 전 최대 60초 대기와 대기 중 중지를 지원합니다.
- 좌표를 포함한 순차 실행 단계를 복제할 수 있습니다.
- 업데이트해도 기존 설정이 유지됩니다.

macOS에서는 손쉬운 사용 권한이 필요합니다. Linux 클릭 기능은 X11에서 사용할 수 있으며 긴급 정지를 보장할 수 없는 Wayland에서는 차단됩니다. Windows 설치 파일은 미서명 상태로 SmartScreen 경고가 나타날 수 있습니다.

## 日本語

- 設定を JSON ファイルにバックアップし、別のインストールで読み込めます。無効なファイルやキャンセル時は現在の設定を保持します。
- 開始前に最大60秒待機でき、待機中も停止できます。
- 位置を含むシーケンスのステップを複製できます。
- アップデート後も既存の設定を保持します。

macOS ではアクセシビリティの許可が必要です。Linux のクリック機能は X11 で利用でき、緊急停止を保証できない Wayland では無効です。Windows インストーラーは未署名のため SmartScreen の警告が出る場合があります。
